## SpeedTAS

A static website on GitHub Pages plus a robot (GitHub Actions) that keeps its data fresh. The browser does all the maths; the robot only collects data, draws preview pictures and checks the site.

### Website

Everything the visitor's browser runs. One HTML page, one stylesheet and twelve plain JavaScript files loaded in order. They share one global scope, so a later file can use anything from an earlier one.

Good to know: Load order matters only for code that runs immediately; inside functions anything can be used. To add a file, add a script tag in index.html and a row in the README.
